# Posodobi primerjavo modelov

Output: a branch `modeli/YYYY-MM` with changes to `src/data/modeli.yaml`, `src/data/narocnine.yaml`,
`src/data/statistika.json` and `src/data/razpisi.yaml`, and an open PR.
**Never merge, never push to `main`.** Read `/Users/anze/Desktop/Claude/ej-aj/AGENTS.md` first.

Every `gh` and network `git` command needs the prefix
`GH_TOKEN="$(gh auth token --user ej-aj-pro 2>/dev/null || gh auth token --user AnzeNocAI)"` (the active gh account is a different one and
must not be switched).

## 1. Worktree

```bash
cd /Users/anze/Desktop/Claude/ej-aj
GH_TOKEN="$(gh auth token --user ej-aj-pro 2>/dev/null || gh auth token --user AnzeNocAI)" git fetch origin
MONTH=$(date +%Y-%m)
WT=/Users/anze/.cache/ej-aj-worktrees/modeli-$MONTH
mkdir -p /Users/anze/.cache/ej-aj-worktrees
git worktree add "$WT" -b "modeli/$MONTH" origin/main
cd "$WT" && npm ci --silent
```

If `modeli/$MONTH` already exists on origin, stop and report.

## 2. Re-check every model (parallel subagents)

Split `src/data/modeli.yaml` by provider. Launch one subagent per provider in a single message
(`subagent_type: general-purpose`, `model: sonnet`), each with its entries and this task:

> For each model below, open the URLs in `viri` and the provider's current pricing and models
> pages with WebFetch. Report the current standard API price (USD per million input and output
> tokens, not batch, lowest standard tier), context window in tokens, whether it is still
> offered, and any newer model from the same provider that replaced it or is now the flagship.
> Only report values you saw on an opened page, with the URL. Return JSON:
> `{"models": [{"id", "cena_vhod", "cena_izhod", "kontekst", "still_offered", "source_urls",
> "notes"}], "new_models": [{"ime", "why_notable", "cena_vhod", "cena_izhod", "kontekst",
> "source_urls"}], "failed_sources": [...]}`

openai.com often returns 403 to scripts. Then use the OpenAI developer community
announcements, platform docs, or reputable coverage (TechCrunch, The Verge), and name the source.

## 2b. Re-check subscription prices (one more subagent, same message)

Launch one more subagent for `src/data/narocnine.yaml` with this task:

> For each plan below, open the URL in `vir` and report the current price per user per month
> (monthly billing and annual billing), currency, whether VAT is included, and minimum seats.
> Prefer pages localised for Slovenia (EUR). WebFetch sees US prices; if a page only shows USD
> there, use the built-in browser (it runs in Slovenia) and say so. Only report values you saw
> on an opened page. Return JSON: `{"plans": [{"id", "cena_mesec", "cena_letno", "valuta",
> "ddv", "min_uporabnikov", "source_url", "notes"}], "new_plans": [...], "failed_sources": [...]}`

Microsoft has Slovenian EUR prices (excl. VAT) at
https://www.microsoft.com/sl-si/microsoft-365-copilot/business (found 27 September 2026); use
them instead of the US page. Mistral's pricing page lets you pick the country: use Slovenia
(30,49 € for Team in September 2026), not France.

## 2c. Refresh the statistics page (while the subagents run)

`/statistika/` reads `src/data/statistika.json`, which is generated by a script straight from the
sources (Eurostat API, Microsoft AI Diffusion CSV on GitHub, StatCounter CSV). Never edit its
numbers by hand.

```bash
node scripts/osvezi-statistiko.mjs
```

- `Brez sprememb v podatkih.`: run `git checkout src/data/statistika.json` (only the date
  changed; do not commit that alone).
- `NAPAKA: ...`: a source changed its format or is down. Restore the file with
  `git checkout src/data/statistika.json`, continue with the rest, and report the error in the
  PR and the final message. Do not work around it by typing numbers in.
- Changes: keep the file. Years, ranks and headline numbers on the page and in the homepage
  teaser (`src/pages/index.astro`) update automatically. The interpretive sentences in
  `src/pages/statistika.astro` do not. Launch one fact-checker subagent (`general-purpose`) with
  the diff printed by the script, the new JSON and the page, and this task: "Check every prose
  sentence in the page against the new data. List each sentence that is no longer true (for
  example 'razlika manj kot dve odstotni točki', 'največkrat za varnost IKT', 'približno pol manj',
  the order of reasons, 'v vseh starostnih skupinah višji', 'za 5 držav podatka ni'), with a
  corrected Slovenian sentence. Also check the StatCounter month range and that new Eurostat or
  SURS releases do not need a new source link." Apply its fixes, following `docs/slog.md`.
- When a new Eurostat year appears (usually in the autumn), mention it at the top of the PR: it
  changes the headline numbers on the homepage.

## 2d. Re-check funding calls (one more subagent, same message as 2 and 2b)

`/razpisi/` lists public funding for AI in Slovenia from `src/data/razpisi.yaml`. Launch one
subagent (`general-purpose`) with the file and this task:

> For every entry, open `vir` and each URL in `viri` with WebFetch and report: is the call still
> open, closed, or has a new round been published; the current deadline (and cut-off dates);
> who can apply; co-financing share or amount; whether the text mentions AI. Then look for new
> calls or vouchers that fund AI, digitalisation that includes AI, or AI training for Slovenian
> companies or organisations, only on the funders' own pages: podjetniskisklad.si (vavčerji,
> javni razpisi), gov.si (Javne objave), aris-rs.si (Razpisi), srips-rs.si (Vsi razpisi),
> uradni-list.si (Razpisi, search "umetna inteligenca" and "digital"), the Slovenian EDIH and
> AI factory sites, and the EU Funding & Tenders portal for SME calls on AI. Only report values
> you saw on an opened page, with the URL. Return JSON: `{"entries": [{"id", "status",
> "rok", "rok_datum", "kdo", "kaj", "sredstva", "ai", "source_urls", "changes"}],
> "new_calls": [...], "failed_sources": [...]}`

Then in `src/data/razpisi.yaml`:
- Change only what the subagent confirmed on the funder's page; set `preverjeno` to today for
  every entry re-checked. Never take a fact from news sites, consultants or memory.
- A call whose deadline passed: set `status: zaprt`. Remove `zaprt` entries whose deadline is more
  than about four months old, unless a new round is announced.
- New calls: add them with `vir` on the funder's page. Write `kdo`, `kaj` and `ai` in plain
  Slovenian (`docs/slog.md`); `ai` says plainly whether the call text mentions AI or only
  digitalisation.
- New or changed calls get the same fact-check as other content: a separate fact-checker
  subagent opens every source and checks every number, date and name. List the calls in the PR
  (section "Razpisi": added, closed, removed, changed).

## 3. Update the YAML

- Same rules for `src/data/narocnine.yaml`; `kaj_dobite` stays a short Slovenian summary of
  what the page lists.
- Change only values a subagent confirmed on an opened page. Set `preverjeno` to today for
  every entry you re-checked, and update `viri` if the source moved.
- A model that is no longer offered: remove it and say so in the PR.
- New models: add at most the flagship and one budget model per provider. The table should
  stay under about 20 rows. Write `za_kaj` in Slovenian as a practical recommendation for a
  Slovenian company (one sentence), and `opomba` only for facts from the source.
- Slovenian copy, no em or en dashes.

## 4. Check, commit, PR

```bash
npm run build
git add src/data/modeli.yaml src/data/narocnine.yaml src/data/statistika.json src/pages/statistika.astro src/data/razpisi.yaml
git commit -m "Refresh model comparison ($MONTH)"
GH_TOKEN="$(gh auth token --user ej-aj-pro 2>/dev/null || gh auth token --user AnzeNocAI)" git push -u origin "modeli/$MONTH"
GH_TOKEN="$(gh auth token --user ej-aj-pro 2>/dev/null || gh auth token --user AnzeNocAI)" gh pr create --repo ej-aj-pro/ej-aj --base main \
  --head "modeli/$MONTH" --title "Modeli in cene: osvežitev $MONTH" --body-file <body.md>
```

PR body (Slovenian): a table of changes (model, field, old, new, source), added and removed
models, a section "Statistika" with the script's list of changed values and the sentences you
rewrote (or "brez sprememb"), a section "Razpisi", sources that failed, and "Merge = objava na ej-aj.si". If nothing changed, do not open
a PR; report "brez sprememb" instead and delete the branch.

Remove the worktree at the end: `git -C /Users/anze/Desktop/Claude/ej-aj worktree remove "$WT"`.

## 5. Final message

Slovenian, short: PR link (or "brez sprememb"), the list of changes (models, prices, statistics, funding calls),
failed sources.
